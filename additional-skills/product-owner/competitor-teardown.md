# Skill: Competitor Teardown Analysis

## Metadata
- **Owner**: Patrick (Product Owner)
- **Slug**: competitor-teardown
- **Purpose**: Market feature gap analysis, UX teardowns, and strategic differentiation matrices.

## Operational Rules & Guidelines
1. **Focus on Real Differentiation**: Don't clone features blindly. Identify what competitors do poorly and solve the pain point directly.
2. **Pricing & Packaging Comparison**: Compare tier limitations, API call allowances, and value metrics.
3. **Friction Analysis**: Document how many steps a user takes to achieve value on competing platforms.

## Procedures
- Step 1: Benchmark top 3 competing solutions in the domain.
- Step 2: Create a comparison matrix covering UX, performance, and pricing.
- Step 3: Present findings in `/.myemployee/PRD.md` to help Bos make strategic product decisions.
